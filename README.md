# GitHub User Finder

GUI-приложение для поиска пользователей GitHub с сохранением избранного.

## Функции
- Поиск пользователя по имени
- Показ логина, имени и количества подписчиков
- Добавление в избранное
- Просмотр и удаление из избранного
- Сохранение избранного в `favorites.json`

## Требования
- Python 3.11
- Библиотеки: `requests`, `tkinter`

## Установка и запуск
```bash
git clone <your-repo-url>
cd github_user_finder
pip install requests
python main.py
